## 1. 产品定位与边界

### 1.1 一句话定位

用户描述身体不适或想了解健康知识时，平台用 AI 把**模糊的主诉**整理成**清晰的科室与医生选择**，并在咨询前后提供可信、可溯源的信息支持。

### 1.2 用户与场景

| 用户      | 典型场景          | 核心诉求              |
| ------- | ------------- | ----------------- |
| 年轻上班族   | 熬夜后头晕、体检报告有箭头 | 快速知道"要不要去医院、挂什么科" |
| 慢病人群    | 高血压/糖尿病日常监测   | 记录 + 异常提醒 + 复诊时机  |
| 家有老人小孩者 | 帮家人问诊、看不懂报告   | 代为咨询、报告解读、用药提醒    |
| 轻度焦虑用户  | 网上搜症状越搜越怕     | 权威信息 + 有人给个方向     |

### 1.3 不做清单（写进产品，也写进 UI）

1. 不输出疾病诊断结论（禁止"你可能患有 XX"）
2. 不推荐处方药、不给剂量
3. 不承诺疗效
4. 不替代线下就诊
5. 紧急情况不接诊，直接引导 120

## 3. 模块需求详述

### 3.1 健康百科（AI 问答）

**目标**：用户提问后得到有来源、有边界、能追问的答案，而不是一堆搜索链接。

**主流程**

```
用户输入问题
  → 意图识别（科普问答 / 求诊断 / 紧急情况 / 超范围）
      ├─ 紧急情况 → 红旗拦截页（见 §7.2）
      ├─ 求诊断   → 引导至"症状匹配医生"，不给结论
      ├─ 超范围   → 明确拒答 + 建议就医
      └─ 科普问答 → 向量检索 Top-K 词条
                      → 相关性阈值判断
                          ├─ 命中 → 生成答案（附来源 + 更新时间 + 审核人）
                          └─ 未命中 → 兜底回复："暂无权威内容" + 转人工/找医生
                      → 生成 3 条追问建议
                      → 底部固定"以上内容仅供参考，不能替代医生诊断"
```

**词条数据结构**

| 字段              | 类型       | 说明                      |
| --------------- | -------- | ----------------------- |
| entry_id        | string   | 主键                      |
| title           | string   | 词条名                     |
| aliases         | string[] | 别名（影响召回）                |
| department_code | string   | 归口科室                    |
| category        | enum     | 症状/疾病/检查/用药常识/生活方式      |
| summary         | string   | 一句话概述                   |
| content         | text     | 正文（分节：是什么/为什么/怎么办/何时就医） |
| seek_care_signs | string[] | **就医指征**（AI 回答必须带这段）    |
| source          | string   | 指南/权威来源名称               |
| source_url      | string   | 可点开的原始来源                |
| reviewer        | string   | 审核人                     |
| reviewed_at     | date     | 审核日期                    |
| valid_until     | date     | 有效期（过期自动下线待复审）          |
| embedding       | vector   | 向量                      |

**AI 输出规范（硬约束）**

| 约束      | 具体要求                             |
| ------- | -------------------------------- |
| 必须带来源   | 答案末尾显示"来源：XX 指南（2024 版）"，无来源不许输出 |
| 必须带就医指征 | 从 `seek_care_signs` 字段直出，不由模型生成  |
| 禁用词     | 「确诊」「你患了」「建议服用」「治愈率」             |
| 长度      | 正文 ≤ 300 字，超出折叠"展开更多"            |
| 拒答      | 命中阈值不足时禁止生成，防止幻觉                 |

**验收标准**

- [ ] 50 条测试问题中，不需要回答的（求诊断/超范围）拒答率 100%
- [ ] 每条答案均含来源与更新时间
- [ ] 单次响应 P95 < 4s
- [ ] 词条过期后不再进入召回

### 3.2 症状描述 → 匹配医生（核心链路）

**目标**：把用户"我最近老是头晕"这类模糊描述，转成"神经内科 + 3 位可选医生"。

**输入设计（两段式）**

第一段：自由文本（必填，≥10 字）  
第二段：结构化补全（AI 抽取后回填，用户可改）

| 字段     | 形式                 | 必填 |
| ------ | ------------------ | -- |
| 主要不适部位 | 人体图点选 / 多选         | 是  |
| 症状性质   | 胀痛/刺痛/钝痛/烧灼/麻木/其他  | 否  |
| 持续时间   | 数小时 / 数天 / 数周 / 数月 | 是  |
| 严重程度   | 1~10 分             | 否  |
| 伴随症状   | 多选（发热/恶心/乏力/心悸…）   | 否  |
| 既往病史   | 多选（高血压/糖尿病/过敏史）    | 否  |
| 正在用药   | 文本                 | 否  |
| 图片     | 最多 3 张（患处/报告）      | 否  |

**处理链路**

```
自由文本 + 结构化项
  → ① 红旗症状检测（规则优先，先于一切）
       命中 → 中断流程，进入急救引导页
  → ② 症状实体抽取（部位/性质/时长/程度/伴随/既往）
  → ③ 科室映射（多科室候选 + 置信度）
       置信度 < 0.6 → 不直接给结果，让用户在 Top3 科室中选择
  → ④ 医生召回（科室 + 亚专业 + 在线状态）
  → ⑤ 排序打分
  → ⑥ 结果页（推荐科室说明 + 医生卡片 + 「为什么推荐」可展开）
```

**排序权重**

| 维度               | 权重  | 说明                 |
| ---------------- | --- | ------------------ |
| 科室/亚专业匹配度        | 35% | 主权重                |
| 患者评价分            | 25% | 需 ≥20 条评价才计入       |
| 职称               | 15% | 主任/副主任/主治          |
| 响应速度（历史平均首次回复时长） | 15% |                    |
| 价格               | 10% | **不因病情严重度上浮推荐高价款** |

**「为什么推荐」文案**（可解释性是差异化点）

> 推荐理由：你描述的症状集中在「头部 + 眩晕 + 持续数天」，属于神经内科常见主诉；张医生擅长眩晕与头痛方向，近 30 天平均 2.1 小时回复。

**异常与兜底**

| 情况               | 处理                   |
| ---------------- | -------------------- |
| 抽取失败             | 降级为纯科室选择器            |
| 多科室并列            | 展示 Top3 科室让用户选，不硬猜   |
| 医生全部离线           | 展示"预计 X 小时回复"，并给百科入口 |
| 红旗命中             | 全屏急救引导，不可跳过被误关       |
| 用户反复描述同一症状 3 次以上 | 提示线下就诊更合适            |

**验收标准**

- [ ] 红旗症状召回率 **100%**（测试集 30 条，漏 1 条即不通过）
- [ ] 科室 Top1 命中率 ≥ 80%（测试集 100 条）
- [ ] 结构化字段抽取准确率 ≥ 85%
- [ ] 从进入描述页到医生列表 P95 < 6s

### 3.3 名医咨询（异步单次问答）

**目标**：患者提交一次，医生 24 小时内回复一次，闭环可评价、可退款。

**状态机**

```
待支付 ──支付成功──> 待接诊 ──医生接单──> 已接诊 ──提交回复──> 已完成 ──> 已评价
   │                    │                    │
   └─取消              └─24h 未接单─> 已退款  └─48h 未回复─> 已退款
```

| 状态  | 允许操作       | 超时规则                       |
| --- | ---------- | -------------------------- |
| 待支付 | 支付 / 取消    | 30 分钟未付自动关闭                |
| 待接诊 | 取消（全额退）    | 医生 24h 未接单 → 自动退款 + 通知     |
| 已接诊 | 补充图片（≤2 张） | 医生 48h 未回复 → 自动退款 + 扣医生响应分 |
| 已完成 | 评价（7 天内）   | —                          |

**患者侧流程**

```
医生详情页 → 「立即咨询」
  → 病情表单（自动带入 3.2 的结构化结果，可修改）
  → AI 生成预问诊摘要（患者可编辑、可关闭）
  → 确认页：价格 / 回复时效承诺 / 免责声明勾选
  → 支付 → 待接诊页（可看排队位置）
  → 医生回复 → 站内信 + 订阅消息通知
  → 查看回复 → 评价
```

**AI 预问诊摘要（核心价值点）**

把患者零散描述整理成医生 10 秒能读完的结构：

```
【主诉】头晕伴乏力 5 天
【现病史】5 天前晨起出现头晕，体位改变时加重，持续约 10 分钟；
          伴轻度乏力，无恶心呕吐，无耳鸣。
【既往史】高血压 3 年，规律服用氨氯地平
【近期数据】近 7 天血压 145~158/88~95 mmHg（附趋势图）
【已尝试】自行休息，未用药
【患者疑问】是否需要调整降压药
【附件】血压记录截图 1 张
```

**医生端（单页工作台）**

| 区域 | 内容                         |
| -- | -------------------------- |
| 左栏 | 患者预问诊摘要 + 原始描述 + 图片 + 历史咨询 |
| 右栏 | 回复输入框 + 常用语模板 + AI 回复草稿    |
| 顶部 | 倒计时（剩余回复时间）+ 订单金额          |

**AI 给医生的回复草稿规则**

- 草稿必须医生**手动编辑后**才能发送，不允许一键发送
- 草稿禁用词与百科一致（不出现药名 + 剂量组合）
- 涉及用药调整的，草稿自动改为"建议线下复诊评估"

**验收标准**

- [ ] 全部状态流转可复现，退款路径无死角
- [ ] 预问诊摘要平均生成时间 < 5s
- [ ] 超时自动退款任务准确率 100%
- [ ] 医生无法发送含处方药 + 剂量的回复（拦截提示）

### 3.4 日常健康管理

**目标**：低负担记录 + 看得懂的解读。

**两个输入入口**

| 入口       | 交互                     | 负担 |
| -------- | ---------------------- | -- |
| 打卡（主）    | 首页卡片，点一下填数字，10 秒完成     | 低  |
| 报告拍照（增强） | 拍化验单/体检报告 → OCR → 抽取指标 | 中  |

**打卡指标**

| 指标 | 单位     | 频次  | 异常阈值示例        |
| -- | ------ | --- | ------------- |
| 血压 | mmHg   | 每日  | ≥140/90 提示偏高  |
| 血糖 | mmol/L | 每日  | 空腹 ≥7.0 提示偏高  |
| 体重 | kg     | 每周  | 30 天波动 >5% 提示 |
| 睡眠 | 小时     | 每日  | <6h 连续 3 天提示  |
| 用药 | 是/否    | 按医嘱 | 漏服连续 2 次提示    |

**报告识别流程**

```
拍照/上传 → 图像质量检测（模糊则重拍提示）
  → OCR → 指标抽取（项目名 / 结果值 / 单位 / 参考范围）
  → 与参考范围比对，标记 ↑↓
  → 逐项通俗解释（这条指标反映什么）
  → 汇总提示：「本次有 3 项异常，建议带上报告咨询内科医生」
  → 一键「带着这份报告去咨询」
```

**AI 解读约束**

- 只解释**指标含义与偏离方向**，不推断疾病
- 结论统一收口为"建议咨询医生 / 建议复查"
- 每条解读标注"AI 生成，仅供参考"

**提醒**

用药提醒、测量提醒、复诊提醒。小程序订阅消息，支持自定义时间与重复规则。

**验收标准**

- [ ] 打卡流程 ≤3 次点击完成
- [ ] 常见化验单（血常规/生化/尿常规）指标抽取准确率 ≥ 90%
- [ ] 识别失败有明确重拍引导，不出现空白页
- [ ] 提醒触达率 ≥ 95%

### 3.5 病情交流（开放式论坛）

**目标**：让同病相怜的人互相支撑，同时把风险挡在门外。

**结构**

- 版块：按病种（高血压、糖尿病、失眠焦虑、皮肤问题、儿科、妇科、其他）
- 帖子：标题 + 正文 + 图片（≤9 张）+ 病种标签
- 互动：评论、点赞、收藏、举报

**AI 四道审核（发帖与评论同步生效）**

| 序号 | 检测项                                | 判定 | 处置                                |
| -- | ---------------------------------- | -- | --------------------------------- |
| ①  | 医疗广告 / 导流（微信、电话、"加我"、"老中医"、卖药、代挂号） | P0 | **直接拦截**，不入库，记违规                  |
| ②  | 自伤 / 自杀 / 极端情绪（"不想活了""结束生命"等）      | P0 | 放行但立即向作者弹出危机干预卡（心理援助热线）+ 推送人工介入任务 |
| ③  | 无资质诊疗建议（"你这个吃 XX 药就行""不用去医院"）      | P1 | 折叠该段 + 加提示"个人经验，请以医生意见为准"         |
| ④  | 隐私泄露（手机号、身份证、住址、病历号、真实姓名）          | P1 | 自动脱敏打码后发布                         |

**补充规则**

| 情形                    | 处置        |
| --------------------- | --------- |
| 夸大疗效、绝对化表述（"根治""百分百"） | P2 加提示标签  |
| 图片含他人面部/病历            | 转人工复核     |
| 同一账号 24h 内发帖 >5 条     | 限流 + 转人工  |
| 被举报 3 次以上             | 自动隐藏待人工判定 |

**强制展示**

- 每条帖子底部固定："以上为个人经验分享，不构成医疗建议。如有不适请及时就医。"
- 每个版块顶部固定免责声明
- 帖子内提供"问医生"入口（把帖子内容一键转为咨询单）

**验收标准**

- [ ] 广告导流拦截率 ≥ 95%（测试集 100 条）
- [ ] 危机关键词 100% 触发干预卡
- [ ] 隐私脱敏不误伤正常内容（误伤率 < 5%）
- [ ] 审核结果回写延迟 < 3s

### 3.6 我的

| 功能    | 要点                                                       |
| ----- | -------------------------------------------------------- |
| 就诊人档案 | 本人 + 最多 5 位家人（关系、性别、出生日期、过敏史、既往史）；咨询时可切换就诊人              |

## 5. AI 能力清单与降级策略

| #  | 能力        | 输入          | 输出             | 失败降级                  |
| -- | --------- | ----------- | -------------- | --------------------- |
| 1  | 症状实体抽取    | 自由文本        | 结构化 JSON       | 规则关键词匹配 → 纯表单填写       |
| 2  | 科室映射      | 结构化症状       | 科室 + 置信度       | 关键词→科室映射表 → 让用户自选     |
| 3  | 红旗症状检测    | 全文          | 命中/未命中 + 规则 ID | **纯规则引擎实现，不依赖模型**     |
| 4  | 预问诊摘要     | 病情表单 + 历史数据 | 结构化摘要          | 模板拼接原字段               |
| 5  | 百科 RAG 问答 | 问题          | 答案 + 来源        | 返回词条列表让用户自读           |
| 6  | 医生回复草稿    | 摘要          | 草稿文本           | 隐藏该功能，仅给常用语模板         |
| 7  | 化验单 OCR   | 图片          | 指标表            | 提示重拍 / 手动录入           |
| 8  | 指标解读      | 指标表         | 通俗说明           | 仅显示 ↑↓ 标记，不给文字解读      |
| 9  | 内容审核      | 帖子文本+图片     | 分级 + 处置        | **降级为关键词黑名单 + 全部转人工** |
| 10 | 危机识别      | 文本          | 风险等级           | 关键词表兜底（宁可误报）          |

**统一降级原则**：AI 不可用时，宁可少功能，不可给错误信息。所有降级路径必须有 UI 兜底，不能出现空白页或转圈。

## 7. 安全与合规设计

### 7.1 定位红线（写进开发规范）

| 红线 | 落地方式 |
|---|---|
| 不做诊断 | AI 输出禁用词表 + 输出后置校验 |
| 不开处方 | 咨询回复中"药名 + 剂量"组合直接拦截发送 |
| 不替代线下 | 每个 AI 输出下方固定免责条 |
| 不承诺疗效 | 内容审核规则库 |

### 7.2 红旗症状规则（示例，需运营可配置）

| # | 触发条件 | 动作 |
|---|---|---|
| 1 | 胸痛/胸闷 + 出汗/放射至左臂/濒死感 | 全屏提示：立即拨打 120，勿自行驾车 |
| 2 | 突发口角歪斜 / 单侧肢体无力 / 言语不清 | 卒中预警，立即 120 |
| 3 | 呼吸困难 / 口唇发紫 / 无法平卧 | 立即 120 |
| 4 | 大量出血不止 / 呕血 / 黑便 | 立即急诊 |
| 5 | 意识丧失 / 抽搐 / 呼之不应 | 立即 120 |
| 6 | 雷击样剧烈头痛（数秒达高峰） | 立即急诊 |
| 7 | 高热 + 颈项强直 / 皮下出血点 | 立即急诊 |
| 8 | 孕妇腹痛 / 阴道出血 / 胎动消失 | 立即产科急诊 |
| 9 | 儿童精神萎靡 / 抽搐 / 呼吸急促 | 立即儿科急诊 |
| 10 | 服毒 / 过量服药 / 自伤 | 立即 120 + 中毒咨询 |
| 11 | 自杀 / 自残意念表达 | 危机干预卡 + 心理援助热线 + 转人工 |

**规则实现要求**：规则引擎独立于 LLM，模型不可用时也必须生效；命中后流程不可被"继续咨询"按钮绕过。

### 7.3 免责声明布置

| 位置 | 文案要点 |
|---|---|
| 首次进入 | 弹窗确认：本平台提供健康信息与医生咨询撮合，不提供诊断与处方 |
| AI 每次回答 | 底部固定条："以上内容仅供参考，不能替代医生诊断" |
| 咨询下单前 | 必须勾选知情同意 |
| 每条帖子 | 底部固定条 |
| 报告解读结果 | "AI 生成，仅供参考，请以医生意见为准" |

### 7.4 数据与留痕

- 健康数据、咨询内容按敏感个人信息处理，首次使用单独授权
- 所有 AI 调用写入 `ai_log`（输入、输出、模型、耗时）
- 咨询会话内容不可被用户侧彻底删除，保留争议处理所需时长
- 隐私模式只影响**本地展示**，不影响云端留存（UI 需说明）

### 7.5 定级说明

本方案定位为"健康科普 + 咨询撮合"，不开展互联网诊疗，因此**不涉及**：互联网医院资质、电子处方、病历长期留存、医师多点执业备案。若后续升级为在线诊疗，需整体重做合规层（见附录 A）。
