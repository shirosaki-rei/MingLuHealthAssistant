## 三、前端：三步

### 1. 改后端地址（必做，否则真机连不上）

```ts
// android/api/http.ts
export const BASE_URL = 'http://127.0.0.1:8000'   // ← 手机上的 127.0.0.1 是手机自己
```

改成电脑的局域网 IP：

```bash
ipconfig | findstr IPv4
# 例如 172.25.209.140
```

```ts
export const BASE_URL = 'http://172.25.209.140:8000'
```

### 2. 后端要监听所有网卡

```bash
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

只写 `--port` 时默认绑 `127.0.0.1`，手机连不上。

- 普通页面调试：`运行 → 运行到 Android App 基座` 即可（标准基座够用）

```bash
cd D:/Dev/HBuilderX
./cli.exe launch app-android --project "F:/hongmeng/pj1/android" --playground custom --deviceId <设备号>
```

## 四、真机联调的三个拦路虎

按这个顺序排查，每次都能省半小时：

| 现象            | 原因                   | 解法                                                                  |
| ------------- | -------------------- | ------------------------------------------------------------------- |
| 请求超时 / 连接被拒   | 手机和电脑不在同一网段          | 都连同一个 Wi-Fi，关掉手机流量                                                  |
| 浏览器能开、App 打不开 | Android 9+ 禁止明文 HTTP | 项目根目录 `AndroidManifest.xml` 加 `android:usesCleartextTraffic="true"` |
| 全部正常但过一会儿断    | 电脑防火墙                | 放行 8000 端口，或临时关防火墙测一次                                               |

**验证网络的最快方式**：手机浏览器打开 `http://电脑IP:8000/docs`，能出接口文档就说明网络通了。

## 六、常见问题

**429 Too Many Requests**  
发码有 60 秒频控。测的时候换个手机号，或者等一分钟。

**登录一直失败**  
验证码 5 分钟过期。重新发一次，或直接读库：

```bash
python -c "import sqlite3;print(sqlite3.connect('minglu.db').execute('select code from sms_code order by last_sent_at desc limit 1').fetchone())"
```

**对话没有流式效果，一次性出全文**

- 后端：确认用的 `/v1/chat/stream`，不是 `/v1/chat`
- 前端：`api/chat.ts` 里 `enableChunked: true` 是否保留
- 网络：中间有没有代理缓冲（nginx 需关闭 buffering）

**提醒不响**

- Android 13+ 通知权限（运行时）
- 精确闹钟权限（Android 12+）
- ROM 白名单：vivo 要开「后台高耗电」+「自启动」
