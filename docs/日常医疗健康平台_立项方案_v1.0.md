# 日常医疗健康平台 — 立项方案（V1.0）

> 文档类型：内部立项 / 投资评估
> 产品形态：微信小程序（主）+ H5 兜底
> 定位：健康科普 + 医生咨询撮合（非诊疗）
> 编写日期：2026-10-21

---

## 1. 摘要

**问题**：普通人出现身体不适时，面临三个断层——不知道自己该挂什么科；在搜索引擎上越搜越焦虑，且信息无法判断真伪；想找医生问一句，发现正规渠道门槛高（挂号、排队、时间成本）。

**方案**：用 AI 把"模糊主诉"翻译成"该看哪个科、该问哪位医生"，中间用可溯源的健康百科承接焦虑，用打卡和报告解读把一次性咨询变成长期关系。

**不做什么**：不做诊断、不开处方、不卖药。这一条既是合规底线，也是差异化——市面上不缺"能回答问题"的产品，缺的是"知道自己不该回答什么"的产品。

**关键数字**（待核实，见 §10）：

| 指标 | 假设值 |
|---|---|
| 咨询客单价 | 80 元 |
| 平台抽成 | 25% |
| 单笔毛利 | 20 元 |
| 目标付费转化（活跃用户） | 3%~5% |
| 首年目标活跃用户 | 10 万 |

## 2. 市场与机会

### 2.1 需求侧的三个事实

1. **搜索替代不了分诊**。用户搜"头晕"，得到的是疾病清单而不是"挂神经内科"。搜索引擎优化的是信息量，用户要的是决策。
2. **健康焦虑是高频情绪，不是高频消费**。用户每天都在担心，但一年可能只付费问诊一两次。这意味着产品必须用免费内容做入口、用工具做留存、用咨询做变现。
3. **报告看不懂是刚需痛点**。体检报告、化验单上的箭头，是普通人最容易被"吓到"也最容易被"骗到"的场景。

### 2.2 政策环境

- "健康中国 2030" 把健康管理与科普提到国家战略层面
- 互联网诊疗相关管理办法明确：线上只能做**复诊**，须依托实体机构
- 本方案定位在"健康科普 + 咨询撮合"，**不进入诊疗环节**，合规门槛显著低于互联网医院

### 2.3 机会窗口

大厂做的是"供给侧连接"（挂号、问诊、买药），做的是交易闭环；内容平台做的是"流量分发"，做的是注意力。**中间那层——"帮用户想清楚该找谁"——是空的**。这层恰好是最适合 AI 的：不需要医疗资质，只需要把信息整理好。

## 3. 竞品分析

| 产品 | 核心模式 | 优势 | 短板 | 我们的切入 |
|---|---|---|---|---|
| 平安健康 | 自建医生团队 + 保险协同 | 供给稳定、有钱、有支付方 | 重资产、偏交易、内容弱 | 不做重供给，做轻撮合 |
| 好大夫在线 | 医生资源 + 图文问诊 | 医生质量高、严肃医疗心智强 | 门槛高、体验重、年轻用户少 | 降低首次使用门槛 |
| 丁香医生 | 科普内容 + 在线问诊 | 内容审核严格、品牌信任度高 | 内容与咨询衔接较弱 | 内容直接转咨询 |
| 春雨医生 | 图文问诊 + AI 分诊 | 分诊尝试早 | 品牌老化、供给流失 | 分诊做得更深更可解释 |
| 微医 | 挂号 + 互联网医院 | 公立医院连接强 | C 端体验弱 | 不做挂号，做决策辅助 |
| 小红书/抖音健康内容 | UGC 内容流量 | 流量巨大、真实经验多 | 质量参差、误导性强、无闭环 | 用审核与溯源做"可信版" |

**差异化三条**

1. **可解释的匹配**：不只给结果，还给"为什么推荐这位医生"（症状特征 → 亚专业 → 医生擅长 + 响应数据）。这是信任的来源。
2. **内容可溯源**：每一条百科答案带来源、更新时间、审核人；过期内容自动下线。这在 AI 生成内容泛滥的当下是稀缺品。
3. **论坛与咨询打通**：帖子里的真实问题可以一键转成咨询单，医生的回答又回流成内容。形成"经验 → 专业 → 内容"的闭环。

## 4. 目标用户与切入策略

| 阶段 | 人群 | 说明 |
|---|---|---|
| 首期 | 25~40 岁、有慢病或体检异常的城市白领 | 有支付能力、有明确诉求、会用小程序 |
| 二期 | 家有老人小孩的中青年（代问诊人群） | 决策者与使用者分离，付费意愿强 |
| 三期 | 慢病长期管理者 | 从"问一次"变成"管一年" |

**切入路径**：先做透**一个病种**（建议高血压或失眠焦虑），而不是全科铺开。单病种能做出密度——有医生、有内容、有同病相怜的人，密度才有社区氛围。

## 5. 产品方案（浓缩）

完整需求见《日常医疗健康平台 PRD v1.0》，此处只列骨架。

| 模块 | AI 角色 | 用户价值 |
|---|---|---|
| 健康百科 | RAG 问答，带来源与就医指征 | 从"越搜越怕"到"知道该怎么办" |
| 症状匹配医生 | 结构化抽取 + 科室映射 + 可解释排序 | 从"不知道挂什么科"到"3 位可选医生" |
| 名医咨询 | 预问诊摘要 + 医生回复草稿 | 医生 10 秒读懂病情，患者少说废话 |
| 日常健康管理 | 报告 OCR 解读 + 趋势分析 | 看懂箭头，知道要不要紧 |
| 病情交流 | 四道内容审核 + 危机干预 | 有同类人，但不被骗 |
| 安全层 | 红旗症状拦截 + 心理危机干预 | 不该线上解决的，第一时间推到医院 |

**AI 边界（写进产品原则）**：AI 不诊断、不开方、可拒答。AI 做的是信息整理、分诊撮合、风险拦截、持续提醒。

## 6. 商业模式

| 收入项 | 模式 | 预估占比 | 备注 |
|---|---|---|---|
| 咨询抽成 | 订单 20%~30% | 55% | 主收入，与供给强相关 |
| 会员订阅 | 月/年费，含无限次图文咨询 + 报告解读 | 25% | 提升 LTV，降低对单次转化依赖 |
| 企业健康福利 | 向企业售卖员工健康服务包 | 15% | 客单高、获客成本低 |
| 内容品牌合作 | 非处方、非诊疗类的健康品牌专区 | 5% | 严格审核，不接药品与器械导流 |

**明确不做的收入**：处方药销售、药品导流、检查项目导流、以病情严重度定价的竞价排名。这些钱好赚，但会把产品推向"卖药平台"，一旦如此，信任与合规同时崩塌。

## 7. 冷启动与增长

| 阶段 | 动作 | 说明 |
|---|---|---|
| 0→1 | 单病种密度 | 一个病种凑齐 10 位医生 + 200 条优质内容 + 500 名种子用户 |
| 1→10 | 医生个人品牌页 | 医生愿意来的唯一理由：能带来自己的患者。给每位医生一个可分享的主页 |
| 1→10 | 打卡工具做留存钩子 | 打卡是低频医疗里的高频动作，用来维持打开率 |
| 10→100 | 内容搜索流量 | 论坛真实问答 + 百科词条做搜索引擎与小程序搜一搜的长尾 |
| 10→100 | 报告解读做传播点 | "体检报告解读"是天然的朋友圈传播素材（需处理好隐私） |

**留存逻辑**：内容拉新 → 工具留存 → 咨询变现 → 咨询后的记录沉淀再回到工具。四步必须闭环，缺一步就变成一次性工具。

## 8. 单位经济模型（假设测算）

| 项 | 数值 | 说明 |
|---|---|---|
| 咨询客单价 | 80 元 | 图文单次 |
| 平台抽成 | 25% → 20 元 | |
| 支付通道费 | 约 0.6% → 0.5 元 | |
| 单笔净毛利 | ≈ 19.5 元 | |
| 付费转化率 | 3% | 活跃用户中每月付费比例 |
| 单活跃用户月均收入 | ≈ 0.6 元 | 19.5 × 3% |
| 单活跃用户年获收入 | ≈ 7 元 | 不含会员 |
| 内容审核成本 | 0.3~0.8 元/千条 | AI 为主 + 人工抽检 |
| 可承受 CAC | 15~25 元 | 按 2~3 年回收期 |

**结论**：纯靠咨询抽成，单用户年收入仅 7 元左右，无法支撑 15 元以上的获客成本。**必须靠会员订阅 + B 端把这笔账拉平**。这也是为什么"健康管理"模块不是附属功能，而是商业模型的必要组成——它是会员权益的载体。

## 9. 风险与对策

| # | 风险 | 等级 | 对策 |
|---|---|---|---|
| 1 | **论坛出现无资质诊疗建议**，被认定为平台提供诊疗服务 | 🔴 极高 | AI 四道审核 + 分级处置（拦截/折叠/打码/转人工）；每条帖子强制免责；建立违规账号处置与申诉机制 |
| 2 | 咨询回复滑向诊疗（医生建议用药） | 🔴 高 | "药名 + 剂量"组合直接拦截发送；医生话术前置规范；疑似诊疗内容转人工复核 |
| 3 | 医生供给冷启动（无患者不来，无医生无患者） | 🟡 中高 | 单病种切入、医生个人品牌页、前期平台补贴保底收入 |
| 4 | 审核成本随内容量线性增长 | 🟡 中 | AI 前置过滤 + 人工只处理疑难；违规账号限流降低总量 |
| 5 | 医疗纠纷与舆情 | 🔴 高 | 全过程留痕（`ai_log` + 会话记录）；免责声明分层；客服与投诉通道 |
| 6 | 大厂复制 | 🟡 中 | 壁垒不在功能而在"医生密度 + 内容可信度 + 审核能力"，需尽早积累 |
| 7 | 用户把 AI 输出当诊断 | 🟡 中 | 每条输出挂免责；AI 主动拒答求诊断类问题；就医指征强制展示 |

**最高风险是第 1 条**。开放式论坛是产品里最有活力也最危险的部分。它决定了这个产品能不能活——所以审核能力必须作为核心竞争力来建设。

## 附录：三句话总结

1. **卖的不是问诊，是"该找谁"这个决策**。
2. **AI 的价值不在于能回答多少，而在于知道哪些不能答**。
3. **论坛是流量入口也是最大风险源，审核能力就是护城河**。
