### 踩出来的 uni-app x 硬约束（已写进 `android/README.md`）

1. **类型文件必须是 `.ts` 不能是 `.d.ts`**：uts 管线能解析到 `.d.ts` 但会当 JS 解析，
   直接 `Expected '{', got 'interface'`。所以 `openapi-typescript -o types/api.ts`。
2. **`display` 只支持 `flex`/`none`**，`block` 与 `inline-block` 都是编译错误（本次 87 处）。
   view/text 默认就是 flex 纵向排列，想让 text 独占一行就把 `display: block` 删掉。
3. `scroll-view` 的 `scroll-x`/`scroll-y` 已废弃，用 `direction="vertical"`。
4. postgres-in-docker：entrypoint 只初始化**空**数据目录，改 `POSTGRES_PASSWORD` 后旧卷沿用旧密码，
   报 `password authentication failed`，开发库 `docker compose down -v` 重来。

def ops(d):
    return {(m.upper(), p) for p, i in d['paths'].items() for m in i if m in ('get','post','patch','delete','put')}
print('live:', len(ops(live)), 'yaml:', len(ops(spec)), '差集:', ops(spec) ^ ops(live))
PY

# 前端真机编译（设备序列号用 cli devices list 查）
D:/Dev/HBuilderX/cli.exe launch app-android \
  --project "F:/hongmeng/pj1/android" --deviceId <序列号> --playground standard

# 后端容器化
cp .env.example .env && docker compose up --build

`GET /v1/chat/history`——没有第二轮清单可逐条对差，只写能确认的），前端 19 个页面全部有入口。
注意：`CLAUDE.md` 里记的是 39，比实测少 1——那句话已按实测改成 40，以后以 `openapi.json` 为准。
